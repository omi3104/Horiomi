Privacy Policy

Horiomi · last updated 10 September 2026

Horiomi is a personal, self-hosted automation that generates short history videos and uploads them to its operator's own YouTube channel. It runs as a scheduled GitHub Actions job. It has no user accounts, no website sign-in, and no visitors other than its single operator.

What Google data it accesses

  • A single OAuth scope: https://www.googleapis.com/auth/youtube.upload, used only to upload finished video files to the account owner's YouTube channel via the YouTube Data API v3.
  • No other Google account data is read, requested, or received.

What it stores

  • One OAuth refresh token, held as an encrypted GitHub Actions secret so the scheduled job can authenticate. It is never displayed or transmitted anywhere except to Google's token endpoint.
  • No personal data, viewer data, analytics, cookies, or tracking of any kind is collected or retained.

Sharing

Nothing is shared, sold, or disclosed to any third party. Data obtained through Google APIs is used solely for the upload function described above, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Data removal

The operator can revoke the app's access at any time at myaccount.google.com/permissions, which immediately and permanently ends all access.
